## 3. Project Module 1: Password Cracking with JTR

### Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Online PDF Hash Extractor
- Notepad
- Windows PC

### Implementation

The first exercise involved recovering the password of a protected PDF document using John the Ripper and its graphical interface, Johnny.

The following steps were performed:

1. Downloaded and extracted the John the Ripper Windows package.
2. Installed and configured the Johnny graphical interface.
3. Located the `john.exe` executable inside the `run` directory and configured Johnny to use the backend.
4. Uploaded the protected PDF document to an online PDF hash extractor to obtain its password hash.
5. Copied the extracted hash and saved it in a text file named `hash1.txt`.
6. Opened Johnny and imported the hash file using the **Open Password File** option.
7. Started a new password-recovery attack.
8. Allowed John the Ripper to process password candidates until the password was recovered.
9. Used the recovered password to open the protected PDF document.

### Outcome

Successfully completed the PDF password-recovery exercise using John the Ripper and Johnny. This provided practical exposure to configuring a password-cracking backend, importing password hashes, and performing password recovery through a graphical interface.

## 4. Project Module 2: Password Cracking with NetworkWalks Tools

### Tools Used

- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser
- Windows PC

### Implementation

The second exercise involved using NetworkWalks' online tools to extract a password hash from a protected PDF document and recover its password.

The following steps were performed:

1. Downloaded the provided protected PDF document from the NetworkWalks project task page.
2. Accessed the NetworkWalks Hash Calculator through a web browser.
3. Uploaded the protected PDF document to extract its password hash.
4. Copied the complete hash value generated by the Hash Calculator.
5. Opened the NetworkWalks Password Cracker.
6. Pasted the extracted PDF hash into the password-cracking tool.
7. Initiated the password-recovery process and allowed the tool to test password candidates.
8. Retrieved the recovered password.
9. Used the recovered password to open the protected PDF document.

### Outcome

Successfully completed the password-recovery exercise using NetworkWalks' online Hash Calculator and Password Cracker. The exercise demonstrated an alternative approach to password recovery without requiring locally installed password-cracking software.
